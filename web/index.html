    How answers are checked

    1. Search. Keyword and vector search over paragraph-level passages, fused and reranked.
    2. Answer. A language model writes sentences that each cite a passage and quote it.
    3. Check. Code confirms that every quote appears word for word in the cited passage. Sentences that fail are hidden.
    4. Refuse. When no passage scores above the threshold, the page says so instead of guessing.
